# Design System

## Principles

1. Human first.
2. Evidence before decoration.
3. Clear hierarchy.
4. Calm visual rhythm.
5. Subtle interaction.
6. Accessible by default.

## Colors

```text
Ink:           #17212B
Background:    #F7F7F4
Surface:       #FFFFFF
Soft Surface:  #EEF1EF
Accent:        #567568
Accent Light:  #DCE7E0
Secondary:     #657078
Border:        #DDE2DE
```

## Typography

Primary: Manrope

Editorial accent: DM Serif Display

## Radius

Default: 14px

Cards: 14–18px

Pills: only when the control is semantically a pill.

## Spacing

Use a consistent spacing scale. Prefer larger whitespace between major sections and smaller spacing within content groups.

## Shadows

Use minimally. Borders and whitespace should carry most of the hierarchy.

## Motion

200–300ms for normal interactions.

Respect reduced motion.

## Grid

Desktop: 12-column grid, approximately 1180–1240px content width.

Mobile: single-column flow with intentional content ordering.
