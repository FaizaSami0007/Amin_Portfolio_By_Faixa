# Start Here

## 1. Install

```bash
npm install
```

## 2. Run locally

```bash
npm run dev
```

## 3. Build

```bash
npm run build
```

## 4. Before adding final content

Read:
- `docs/CONTENT-VERIFICATION.md`
- `docs/CLIENT-QUESTIONNAIRE.md`
- `docs/DESIGN-SYSTEM.md`
- `docs/UX-HCI.md`
