# Content Verification Checklist

Before publishing the portfolio, verify every public claim.

## Identity
- [ ] Preferred name confirmed
- [ ] Professional title confirmed
- [ ] Short bio approved
- [ ] Long bio approved
- [ ] Location approved
- [ ] Languages approved

## Experience
- [ ] Organization names verified
- [ ] Role titles verified
- [ ] Dates verified
- [ ] Responsibilities verified
- [ ] Outcomes verified
- [ ] Statistics verified

## Recognition
- [ ] Award names verified
- [ ] Awarding organizations verified
- [ ] Years verified
- [ ] Credential URLs verified
- [ ] International program details verified

## Images
- [ ] Portrait approved
- [ ] Event photographs approved
- [ ] Captions verified
- [ ] Usage rights confirmed

## Contact
- [ ] Professional email approved
- [ ] LinkedIn URL verified
- [ ] Other social URLs approved

## Final approval
- [ ] Client reviewed all text
- [ ] Client reviewed all images
- [ ] Client approved public claims
- [ ] Client approved final design
