# UX / HCI Specification

## User Goals

A visitor should be able to:

1. Understand who Amin is.
2. Understand what he works on.
3. Verify major experiences.
4. Explore his journey.
5. See recognition and programs.
6. Contact him.

## Nielsen Heuristics

### Visibility of system status
Forms, loading, success, and errors need clear feedback.

### Match with real world
Use normal professional language rather than technical or marketing jargon.

### User control
Users can navigate freely and return to previous sections.

### Consistency
Use the same component language across all pages.

### Error prevention
Validate forms and prevent accidental destructive actions.

### Recognition over recall
Expose primary navigation and important actions.

### Accessibility
Keyboard navigation, semantic HTML, focus states, alt text, sufficient contrast, and reduced motion.

## Cognitive Load

Avoid:
- too many cards
- too many colors
- excessive animations
- oversized headings in every section
- long paragraphs without substructure

Use:
- short paragraphs
- clear headings
- progressive disclosure
- strong alignment
- meaningful whitespace
